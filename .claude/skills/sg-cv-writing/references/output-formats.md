# 输出格式与模板锁定规则

## 推荐模式

| 用户需求 | 输出模式 | 主要文件 | 执行规则 |
|---|---|---|---|
| 大多数新加坡求职与实习申请 | ATS 安全单栏版 | `.docx`，投递时转为 PDF | 黑字、单栏、标准标题；不使用图标、技能进度条、文本框或装饰侧栏 |
| 用户上传模板并说“严格沿用 NUS 模板” | 用户模板锁定 | 与原文件相同的可编辑格式 | 保留页边距、字体、标题顺序、间距、对齐和分页逻辑；除非用户要求改版，否则只替换内容 |
| 用户要求 NUS 风格，但没有提供模板 | NUS aligned | `.docx` | 遵循 NUS 内容规范和克制的单栏排版；必须称为 NUS aligned，不得称为官方模板或一比一复刻 |
| NTU 本科生或实习申请 | NTU 本科模式 | `.docx` | 使用 `tier-undergrad.md` 的章节顺序与格式，保留重要项目与 CCA |
| SMU 研究生或 resume book | SMU 研究生模式 | `.docx` | 使用四块结构；只有标准化 SMU 场景才严格执行一页限制 |
| 用户明确要求 LaTeX | ATS 安全 LaTeX | `.tex` + PDF | 使用简单单栏结构、标准字体、Unicode 文本和语义化标题；避免多栏宏包、图标和视觉评分条 |
| 用户只要求改 bullets 或做诊断 | 纯内容模式 | 对话或 Markdown | 不强制生成文件，也不擅自套用完整模板 |

## 模板锁定约定

当用户上传模板并明确要求沿用时：

1. 把用户提供的模板作为视觉版式的唯一依据。
2. 保留页面尺寸、页边距、页眉页脚、字体、字号、标题层级、日期对齐、间距、bullet 缩进和章节顺序。
3. 只修改文字和真实内容需要的最小换行变化。
4. 如果内容放不下，清楚说明取舍，并请用户选择缩短内容或放宽模板要求；不得默默把字号缩到难以阅读。
5. 独立重建的版式不得声称是 NUS、NTU 或 SMU 官方模板。

## ATS 校验

在把 PDF 称为可直接投递之前：

- 抽取文本，确认阅读顺序为姓名与联系方式 → 各章节 → 经历条目 → bullets；
- 确认日期、机构名和 bullet 都是可选择文字，而不是图片；
- 确认关键信息没有只放在页眉、页脚、图标、文本框或复杂双栏阅读顺序里；
- 目视检查最终页数、换行、对齐和溢出情况。

## 视觉原则

求职简历里的“好看”，首先意味着干净、一致、容易扫读：

- 使用单栏层级、充足留白和克制的加粗；
- 白底黑字，只使用一个专业字体家族；
- 不放照片、背景水印、信息图、技能进度条或装饰色块；
- 日期、bullets、大小写和间距保持一致。

LaTeX 不是自动更高级。只有当用户想要稳定、可复现的排版，并愿意编辑源文件时才优先使用；默认仍使用 DOCX，因为它更容易修改，也更适合匹配用户上传的高校模板。
